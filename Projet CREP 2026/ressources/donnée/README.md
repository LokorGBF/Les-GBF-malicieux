# Fichier README des ressources

Récapitulatif du dossier `donnée`

## Dossier _donnée_

- `AERIS.url` : raccourci web menant au portail de données atmosphériques **AERIS** 
(https://www.aeris-data.fr/).

- `CAMS.url` : raccourci web vers le jeu de données atmosphériques **CAMS Global Reanalysis (EAC4)** de Copernicus.

- `degres_de_liberte.txt` : contient les valeurs des **degrés de liberté** des principaux gaz atmosphériques (**CO2 : 5, H2O : 6, CH4 : 6, Ar : 3, N2: 5, O2: 5, O3 : 6**), utiles pour les calculs de thermodynamique et de capacité thermique.

- `Données sourcées.pdf` : document regroupant les différentes **valeurs scientifiques et leurs sources** utilisées pour paramétrer le modèle.

- `e490_00a_amo.xls - NewAM0.csv` : base de données contenant le spectre solaire de référence **AM0** (Air Mass Zero), correspondant au **rayonnement solaire hors atmosphère**.

- `Influence_du_CO2_sur_l_influence_de_l_atmosphere.pdf` : synthèse détaillant **l'impact radiatif du CO2** sur le comportement des différentes couches de l'atmosphère.

- `Pression_atm_isotherme.pdf` : explications et équations relatives au modèle de **pression atmosphérique isotherme** utilisé dans nos calculs.
