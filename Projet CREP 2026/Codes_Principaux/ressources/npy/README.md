# Fichier README des ressources

Récapitulatif du dossier `npy`

## Fichier __grid_dev.npy__

- `grid_dev.npy`: contient les tableaux de données matricielles sauvegardés au format **NumPy**. Ce dossier regroupe notamment les 4 fichiers nécessaires pour générer les affichages visuels en **planisphères et en sphères**. Ces données sont disponibles en basse et haute résolution (*low res* et *high res*).
