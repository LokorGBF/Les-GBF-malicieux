# Fichier README des résultats

Récapitulatif du dossier `figures`

## Dossier _figures_

- Ce dossier sert de répertoire de destination pour les **visualisations générées par le modèle**.

- C'est ici que sont automatiquement sauvegardés les **graphiques et les courbes** de la simulation une fois que le programme principal a été lancé. Vous y retrouverez toutes les images de résultats à la fin de l'exécution du code.
